# Hi, I'm Seiya 👋

Member of **[ARES Project](https://github.com/aresproject-jp)** — an inter-university Mars rover team from Tohoku, Keio and other universities across Japan.
We're aiming to become the **first Japanese team to win the [University Rover Challenge](https://urc.marssociety.org/)**. 🏆
